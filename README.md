# CFO Operational Dashboard

## Project Overview
This project is a finance dashboard built to analyze budget vs. actual spend, monthly burn rate, department expenses, and expense category variance.

## Business Problem
Finance teams need a clear way to monitor overspending, track budget performance, and identify the main drivers of cost.

## Objective
To create an executive dashboard that helps stakeholders quickly understand financial performance and make better budget decisions.

## Key Insights
- Actual spend exceeded budget.
- Certain departments contributed more to total spend.
- Expense categories showed clear cost concentration.
- Monthly burn trends helped reveal spending patterns over time.

## Tools Used
- Excel
- Data cleaning and visualization

## Dashboard Features
- Total budget KPI
- Total actual spend KPI
- Variance KPI
- Monthly burn trend
- Department spending analysis
- Expense category breakdown
